# 灯芯专属杭州天气提醒

每天北京时间 07:00 获取杭州当天的天气，并通过 PushPlus 推送“灯芯专属天气提醒”到个人微信。

## 提醒内容

每日提醒包含：

- 杭州当天的天气状况
- 最高和最低温度
- 降水概率与预计降水量
- 最大风速和紫外线指数
- 日出和日落时间
- 根据温度自动生成的穿衣建议
- 根据降雨、雷电、雾、风速和紫外线生成的出行注意事项

提醒对象称为“灯芯”，通知内容标题固定为“灯芯专属天气提醒”。正文采用适合手机窄屏的短行分块格式，天气图标会随晴、阴、雨、雪、雾和雷电变化。

文案包含 12 套完整主题，并按日期轮换：

- 元气鼓励版
- 古风小笺
- 二次元播报风
- 温柔陪伴版
- 俏皮日常版
- 晨间电台版
- 天气侦察版
- 贴心管家版
- 治愈松弛版
- 清爽简报版
- 冒险任务版
- 云朵来信版

每套主题会同时调整天气标题、问候、穿衣栏目、出行栏目、建议措辞和收尾，让整条提醒保持统一语气。

风格按日期自动轮换：同一天重复运行时文案保持一致，第二天会切换到新的组合。穿衣和出行建议还会随当天的天气变化。

示例：

```text
🌧️ 灯芯出门指南｜10月28日

叮咚，灯芯请查收今日份天气。

杭州 · 小雨
12.1°C ~ 19.5°C
降雨 80% ｜ 风速 18.0 km/h
紫外线 3.0 ｜ 降水量 5.2 mm

👕 穿衣小纸条
长袖配薄外套刚刚好。早晚有点凉，别被温差偷偷拿捏。

🚗 出门小叮嘱
- 雨伞务必带上，鞋子尽量选防滑耐湿的。
- 通勤多留一点时间，别和雨点比赛。

🌅 日出 06:08 ｜ 日落 17:17

天气功课交完啦，灯芯慢慢走，平安到达最重要。
```

## 配置步骤

1. 注册并登录 [PushPlus](https://www.pushplus.plus/)，绑定个人微信，获取用户 Token。
2. 新建一个 GitHub 仓库，把本目录中的 `weather.py` 和 `.github/workflows/daily-weather.yml` 上传到仓库根目录。
3. 打开仓库的 `Settings -> Secrets and variables -> Actions`。
4. 新建 Repository secret：

   ```text
   Name: PUSHPLUS_TOKEN
   Secret: 你的 PushPlus Token
   ```

5. 进入仓库的 `Actions` 页面，选择 `Daily Hangzhou Weather`，点击 `Run workflow` 手动测试一次。

## 时间说明

定时表达式是 `0 23 * * *`，GitHub 按 UTC 执行，对应北京时间每天 07:00。

GitHub Actions 的定时任务可能因为平台负载延迟几分钟。如果必须严格在 07:00 发送，建议把同一个脚本放到云服务器、腾讯云函数或阿里云函数计算中运行。

## 天气数据

天气来自 Open-Meteo，位置固定为杭州：

- 纬度：30.2741
- 经度：120.1551
- 时区：Asia/Shanghai

脚本先按 `Asia/Shanghai` 获取北京时间当天日期，再通过 `start_date` 和 `end_date` 明确请求这一天的天气。如果接口返回其他日期，任务会直接报错，不会误发次日天气。

## 微信显示说明

使用 PushPlus 公共微信公众号时，微信卡片顶部的“设备通知”是固定模板名称，代码无法修改。卡片中的“通知内容”会显示“灯芯专属天气提醒”，点击“查看详情”后可查看完整天气、穿衣和出行提醒。
